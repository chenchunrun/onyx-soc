# 账号失陷处置 SOP

## 1. 适用范围

适用于以下场景：

- 异常登录告警
- MFA 疲劳攻击
- 密码泄露后登录成功
- OAuth / SSO 令牌被滥用
- 邮箱、VPN、云控制台账号疑似被盗用

## 2. 调查目标

- 识别账号是否真的被接管
- 确定攻击入口和影响时间窗
- 阻断攻击者当前会话
- 判断是否存在横向扩散或权限滥用

## 3. 核心调查项

- 登录来源 IP、设备、User-Agent、地理位置
- 登录是否绕过常规基线
- 是否存在 MFA 异常
- 是否出现权限提升、邮箱规则、API token、新应用授权
- 是否存在同源 IP 攻击其他账号

## 4. 处置步骤

### 4.1 快速确认

- 核对账号最近登录轨迹
- 核对用户本人是否确认操作
- 核对登录后是否存在敏感动作

### 4.2 立即阻断

- 强制用户下线
- 重置密码
- 撤销 refresh token / session / OAuth 授权
- 必要时临时禁用账号

### 4.3 范围排查

- 查询同来源 IP 是否命中过其他账号
- 查询同时间窗内是否存在批量失败登录
- 查询邮箱规则、文件共享、管理操作、审计记录

### 4.4 恢复与加固

- 强制重新绑定 MFA
- 检查高风险授权应用
- 检查管理员角色、组成员是否被变更
- 补充条件访问或异常登录检测

## 5. 证据保全

- 身份平台审计日志
- VPN / SSO / CASB / 邮箱日志
- 用户确认记录
- 高风险操作审计
