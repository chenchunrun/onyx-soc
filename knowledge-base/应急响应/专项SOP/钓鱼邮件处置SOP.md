# 钓鱼邮件处置 SOP

## 1. 适用范围

适用于以下场景：

- 用户收到可疑钓鱼邮件
- 用户已点击链接或下载附件
- 邮箱、代理、EDR、邮件网关触发钓鱼相关告警

## 2. 处置目标

- 尽快确认影响范围
- 阻断继续传播或进一步失陷
- 收集证据并保留关键日志
- 识别是否已造成凭证泄露、恶意执行或横向影响

## 3. 初始分级建议

### 低

- 仅收到邮件，未点击、未下载、未登录

### 中

- 点击了链接或下载了附件，但尚无执行或账号异常证据

### 高

- 已确认账号泄露、恶意文件执行、邮箱规则被篡改、批量传播

## 4. 核心调查问题

- 发件人、主题、收件范围是什么
- 是否存在同主题批量投递
- 是否有人点击、下载、提交凭证
- 是否产生恶意进程、脚本、子进程、网络连接
- 是否存在异常邮箱规则、异常登录、OAuth 授权

## 5. 处置步骤

### 5.1 收集基础信息

- 邮件主题
- 发件人地址与 Return-Path
- Message-ID
- 收件人范围
- 邮件网关 verdict
- 邮件原始头部和样本附件

### 5.2 研判邮件真实性

- 检查 SPF / DKIM / DMARC
- 检查显示名冒充与域名相似性
- 提取 URL、附件 hash、发件 IP
- 检查 URL 是否跳转、是否需要登录、是否仿冒内部系统

### 5.3 排查用户行为

- 是否点击链接
- 是否下载附件
- 是否打开 Office、压缩包、脚本、可执行文件
- 是否输入账号密码或 MFA

### 5.4 终端调查

- 查 EDR 告警与进程树
- 查附件落地路径和 hash
- 查浏览器访问记录、下载记录、PowerShell / cmd 执行
- 查可疑子进程、持久化项、网络连接

### 5.5 身份调查

- 查账号异常登录
- 查来源 IP、设备、地理位置、时间
- 查邮箱规则、转发规则、OAuth 授权
- 查近期密码修改、MFA 变更、敏感操作

### 5.6 阻断与遏制

- 从邮箱系统批量删除恶意邮件
- 封禁 URL、域名、附件 hash、发件地址
- 隔离受影响终端
- 重置账号密码并强制 MFA 重新绑定
- 撤销可疑会话和 OAuth token

## 6. 保全证据

- 原始邮件 `.eml`
- 附件原件与 hash
- 邮件头部
- EDR 进程树
- 代理 / DNS / 邮件网关 / 身份系统日志

## 7. 复盘关注点

- 邮件为何未被网关拦截
- 用户为何会点击或输入凭证
- 哪些检测规则和阻断策略缺失
- 是否需要补培训、补告警、补隔离流程
