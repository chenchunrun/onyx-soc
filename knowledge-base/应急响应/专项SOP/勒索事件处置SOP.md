# 勒索事件处置 SOP

## 1. 适用范围

适用于以下场景：

- 主机出现批量文件加密
- 出现勒索信、赎金要求、扩展名异常
- EDR 命中勒索行为或批量文件改写
- 备份、共享盘、存储出现异常加密或删除

## 2. 处置目标

- 立即阻断加密扩散
- 优先保护高价值资产和备份
- 确定感染范围和攻击入口
- 评估是否涉及数据外泄

## 3. 初始高优动作

- 立即隔离受影响主机
- 阻断横向连接和远控通道
- 保护备份系统和共享存储
- 冻结高风险账号
- 通知管理层和关键业务方

## 4. 关键调查问题

- 首个受影响主机是哪台
- 是否存在横向移动
- 是否加密前已被数据窃取
- 是否涉及域控、虚拟化、备份系统
- 初始入口是钓鱼、漏洞、弱口令还是远程服务

## 5. 调查步骤

### 5.1 范围确认

- 受影响主机数量
- 受影响共享盘、数据库、备份
- 关键系统是否中招

### 5.2 攻击入口

- 邮件附件与链接
- VPN / RDP / SMB 暴露
- 漏洞利用
- 管理账号失陷

### 5.3 横向移动

- 域控访问
- 管理员账号登录轨迹
- PsExec / WMI / RDP / SMB 使用

### 5.4 数据外泄判断

- 加密前是否有大流量外传
- 是否存在压缩打包、云盘上传、异常外联

## 6. 处置动作

- 隔离受影响主机
- 封禁 IOC 和 C2
- 禁用或重置相关账号
- 暂停高风险互联
- 保护备份和快照
- 启动恢复优先级评估

## 7. 证据保全

- 勒索信样本
- 恶意进程、命令行、任务计划、服务项
- 可疑文件 hash
- 网络连接记录
- 日志快照与磁盘镜像

## 8. 复盘重点

- 初始入口
- 检测延迟
- 隔离时效
- 备份可恢复性
- 身份治理和最小权限缺口
