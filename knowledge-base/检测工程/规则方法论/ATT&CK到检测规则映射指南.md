# ATT&CK 到检测规则映射指南

## 1. 目标

将 ATT&CK 技术条目转化为可执行的检测规则设计输入。

## 2. 映射思路

每条 ATT&CK 技术至少映射以下信息：

- 技术编号
- 攻击行为描述
- 可观察信号
- 数据源
- 检测逻辑
- 调查建议
- 误报来源

## 3. 映射模板

### 技术

- ID：
- 名称：
- 战术：

### 可观察信号

- 进程行为
- 登录行为
- 文件行为
- 网络行为
- 注册表 / 配置变更
- 云 API 行为

### 数据源

- Windows
- Linux
- EDR
- 网络设备
- 邮件
- 身份系统
- 云审计

### 检测逻辑

- 单事件命中
- 多事件关联
- 阈值型
- 基线偏离

### 调查建议

- 先查哪些日志
- 先看哪些字段
- 需要关联哪些资产和账号

## 4. 示例

### T1566 Phishing

- 数据源：邮件网关、代理、身份系统、EDR
- 信号：批量投递、URL 点击、异常登录、附件执行
- 规则方向：
  - 同主题批量邮件
  - 点击后短时间内异地登录
  - 邮件附件落地后触发脚本执行

### T1059 Command and Scripting Interpreter

- 数据源：EDR、Windows Event、Linux Audit
- 信号：PowerShell、cmd、bash、python、wscript 异常执行
- 规则方向：
  - Office/浏览器拉起脚本解释器
  - 编码命令、下载执行、远程载荷

## 5. 使用建议

- 不要停留在 ATT&CK 标签层
- 一定要落到具体字段、具体数据源、具体查询逻辑
- 每条高价值技术至少对应一个检测样例和一个调查样例
