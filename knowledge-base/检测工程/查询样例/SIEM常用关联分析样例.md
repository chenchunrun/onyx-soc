# SIEM常用关联分析样例

## 适用目标

- 多源日志关联研判
- 账号失陷检测
- 横向移动检测
- 钓鱼点击后续行为检测

## 常见关联思路

### 登录成功前后异常

- 多次失败后成功
- 非常用国家/地区首次成功
- 新设备首次成功
- 低风险登录后快速出现高危操作

### 告警串联

- 邮件告警 -> 终端进程异常 -> 代理流量异常
- Web 告警 -> 主机落地文件 -> 权限提升
- 异常凭证使用 -> 横向移动 -> 数据访问

### 横向移动

- 同一账号短时间登录多台主机
- 管理协议爆发式出现
- 同一源主机创建多个远程服务

## 分析字段建议

- `user`
- `src_ip`
- `dst_ip`
- `hostname`
- `process_name`
- `event_id`
- `url`
- `email_subject`

## 输出建议

- 触发链路
- 关键日志源
- 第一可疑动作
- 后续扩散动作
- 证据强度
- 建议处置优先级
