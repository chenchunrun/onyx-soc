# 等保三级安全检查清单

## 版本信息
- 标准：GB/T 22239-2019
- 等级：第三级（S3）
- 最后更新：2026年1月

## 1. 安全通信网络（8.1.x）

### 8.1.1 网络架构 [L3-S3-CJ1]

| 检查项 | 要求 | 检查方法 | 结果 | 备注 |
|--------|------|----------|------|------|
| 网络区域划分 | 应划分不同网络区域（内部网络、边界网络、管理网络） | 检查网络拓扑图、VLAN配置 | | |
| 边界隔离 | 核心业务区域不部署在网络边界 | 检查拓扑图边界设备配置 | | |
| 技术隔离手段 | 区域间有防火墙/隔离设备 | 检查防火墙规则、ACL配置 | | |
| 冗余部署 | 关键通信链路有冗余备份 | 检查双机热备配置 | | |
| 带宽管理 | 按业务重要性分配带宽 | 检查QoS配置 | | |

### 8.1.2 通信传输 [S3-S3-CJ1]

| 检查项 | 要求 | 检查方法 | 结果 | 备注 |
|--------|------|----------|------|------|
| 传输完整性 | 采用密码技术保证通信完整性 | 检查TLS/签名配置 | | |
| 传输保密性 | 采用密码技术保证通信保密性 | 检查加密协议版本 | | |
| 安全通道 | 通信前建立安全通道 | 检查VPN/SSH配置 | | |
| 管理协议加密 | 网络设备管理使用SSH/HTTPS | 检查设备管理配置 | | |
| 无线网络隔离 | 无线与有线网络隔离 | 检查无线控制器配置 | | |
