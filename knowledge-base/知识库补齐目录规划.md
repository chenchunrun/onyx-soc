# 网络安全通用知识库补齐目录规划

本文档用于定义当前 `knowledge-base/` 后续应补齐的通用安全知识结构，重点是把现有“威胁情报 + 平台实现资料”扩展为可支持 SOC、IR、检测工程、治理合规和内部运营的知识底座。

## 当前已有基础

当前仓库中已经具备以下内容：

- `威胁情报/`
  - CVE feed、MITRE ATT&CK 基础、漏洞情报映射
- `threat-intelligence/`
  - threat-intel 生命周期治理、历史包、archive artifact
- `security-automation/`
  - 工具集成与自动化脚本
- `sso-rbac/`
  - 身份与权限配置说明
- `合规基线/`
  - 等保三级检查清单
- `最佳实践/`
  - 漏洞管理最佳实践
- `应急响应/`
  - 已有目录，但内容仍需扩展

## 建议新增一级目录

建议新增以下一级目录，并逐步沉淀标准知识：

1. `检测工程/`
2. `日志与调查/`
3. `资产与身份/`
4. `攻击案例/`
5. `治理合规/`
6. `内部运行手册/`

## 建议的后续落地顺序

1. 先补 `应急响应/专项SOP/` 与 `检测工程/规则方法论/`
2. 再补 `日志与调查/` 和 `资产与身份/`
3. 然后补 `治理合规/` 与 `攻击案例/`
4. 最后补 `内部运行手册/`

这样可以先让知识库具备更强的实战价值，再逐步增强治理和组织沉淀能力。
