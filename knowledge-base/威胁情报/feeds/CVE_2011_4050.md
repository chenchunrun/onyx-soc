# CVE-2011-4050: Buffer overflow in 7-Technologies (7T) Interactive Graphical SCADA System (IGSS) 9.0.0.11200 allows ...

## Basic Information
- **CVE ID**: CVE-2011-4050
- **Published**: 2011-12-27
- **Last Modified**: 2025-04-11
- **Status**: Deferred
- **CVSS Score**: CVSS 2.0: 5.0

## Description
Buffer overflow in 7-Technologies (7T) Interactive Graphical SCADA System (IGSS) 9.0.0.11200 allows remote attackers to cause a denial of service via a crafted packet to TCP port 12401.
