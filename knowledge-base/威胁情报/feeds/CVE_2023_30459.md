# CVE-2023-30459: SmartPTT SCADA 1.1.0.0 allows remote code execution (when the attacker has administrator privileges)...

## Basic Information
- **CVE ID**: CVE-2023-30459
- **Published**: 2023-04-14
- **Last Modified**: 2025-02-06
- **Status**: Modified
- **CVSS Score**: CVSS 3.1: 7.2 (HIGH) CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H

## Description
SmartPTT SCADA 1.1.0.0 allows remote code execution (when the attacker has administrator privileges) by writing a malicious C# script and executing it on the server (via server settings in the administrator control panel on port 8101, by default).
