# CVE-2017-12707: A Stack-based Buffer Overflow issue was discovered in SpiderControl SCADA MicroBrowser Versions 1.6....

## Basic Information
- **CVE ID**: CVE-2017-12707
- **Published**: 2017-08-25
- **Last Modified**: 2025-04-20
- **Status**: Deferred

## Description
A Stack-based Buffer Overflow issue was discovered in SpiderControl SCADA MicroBrowser Versions 1.6.30.144 and prior. Opening a maliciously crafted html file may cause a stack overflow.
