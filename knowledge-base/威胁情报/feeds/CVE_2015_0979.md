# CVE-2015-0979: Heap-based buffer overflow in the SOAP web interface in SCADA Engine BACnet OPC Server before 2.1.37...

## Basic Information
- **CVE ID**: CVE-2015-0979
- **Published**: 2015-03-14
- **Last Modified**: 2025-04-12
- **Status**: Deferred
- **CVSS Score**: CVSS 2.0: 9.0

## Description
Heap-based buffer overflow in the SOAP web interface in SCADA Engine BACnet OPC Server before 2.1.371.24 allows remote attackers to execute arbitrary code via a crafted packet.
