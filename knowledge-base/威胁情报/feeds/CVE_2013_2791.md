# CVE-2013-2791: MatrikonOPC SCADA DNP3 OPC Server 1.2.0 allows remote attackers to cause a denial of service (master...

## Basic Information
- **CVE ID**: CVE-2013-2791
- **Published**: 2013-09-09
- **Last Modified**: 2025-04-11
- **Status**: Deferred
- **CVSS Score**: CVSS 2.0: 7.1

## Description
MatrikonOPC SCADA DNP3 OPC Server 1.2.0 allows remote attackers to cause a denial of service (master-station daemon crash) via a malformed DNP3 TCP packet from the IP address of an outstation.
