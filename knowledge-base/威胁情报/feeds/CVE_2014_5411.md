# CVE-2014-5411: Multiple cross-site scripting (XSS) vulnerabilities in Schneider Electric StruxureWare SCADA Expert ...

## Basic Information
- **CVE ID**: CVE-2014-5411
- **Published**: 2014-09-18
- **Last Modified**: 2025-11-04

## Description
