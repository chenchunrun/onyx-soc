## 1. 框架概述

MITRE ATT&CK（Adversarial Tactics, Techniques & Common Knowledge）是一个基于真实世界观察的对抗性战术和技术知识库。本框架将攻击者的行为组织为战术（tactics）和技术（techniques），用于红蓝对抗、威胁分析、检测工程和安全评估。

### 1.1 战术与技术的区别

| 概念 | 说明 | 类比 |
|------|------|------|
| **战术（Tactic）** | 攻击者的目标（为什么要这样做） | 攻击者的"目的" |
| **技术（Technique）** | 攻击者的方法（具体怎么实现） | 攻击者的"手段" |
| **子技术（Sub-technique）** | 技术的具体实现变体 | 攻击者的"变招" |

## 2. 各战术详解

### 2.1 TA0043 侦察（Reconnaissance）

**目标**：收集目标组织的信息，为后续攻击做准备。

**常见技术**：

| 技术ID | 技术名称 | 描述 | 检测难度 |
|--------|----------|------|----------|
| T1595 | 主动扫描 | 主动扫描目标网络 | 中 |
| T1596 | 搜索开放源 | 从公开资源收集信息 | 低 |
| T1590 | 收集目标网络信息 | 收集域名、IP范围等 | 低 |
| T1589 | 收集目标组织信息 | 收集员工信息、组织结构 | 低 |

**检测建议**：
- 监控来自外部的异常扫描流量
- 关注DNS查询异常（域名暴破）
- 记录外部对Web应用的爬虫行为

### 2.3 TA0001 初始访问（Initial Access）

**目标**：获取网络的初始入口点。

这是攻击链的第一步，也是最重要的防御节点。

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1566 | 钓鱼攻击 | 鱼叉式钓鱼（Spearphishing） | 极高 |
| T1566.001 | 鱼叉式钓鱼附件 | 恶意附件 | 高 |
| T1566.002 | 鱼叉式钓鱼链接 | 恶意链接 | 高 |
| T1566.003 | 通过服务钓鱼 | 通过LinkedIn/Twitter等 | 中 |
| T1190 | 利用面向Internet的系统 | 利用VPN、Web应用漏洞 | 高 |
| T1133 | 外部远程服务 | 利用RDP/VPN/SSH | 高 |
| T1078 | 有效账户 | 使用窃取或弱口令账户 | 极高 |
| T1078.004 | 云IAM账户 | 利用云平台账户 | 高 |

**初始访问向量优先级排序**（基于实际攻击统计）：

1. **钓鱼攻击（T1566）** — 最常见，尤其是鱼叉式钓鱼
2. **有效账户（T1078）** — 凭证泄露和弱口令
3. **利用面向Internet的系统（T1190）** — VPN、Exchange、Log4j等
4. **外部远程服务（T1133）** — RDP暴力破解、VPN利用

**防御建议**：
- 强制MFA（尤其是外部访问）
- 定期安全意识培训和钓鱼演练
- 及时打补丁（特别是面向Internet的系统）
- 监控RDP/VPN登录异常

### 2.4 TA0002 执行（Execution）

**目标**：在目标系统上运行恶意代码。

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1059 | 命令和脚本解释器 | 使用脚本执行 | 极高 |
| T1059.001 | PowerShell | 利用PowerShell执行命令和脚本 | 极高 |
| T1059.003 | Windows命令外壳 | cmd.exe执行命令 | 高 |
| T1059.004 | Unix Shell | Bash/Sh执行 | 高 |
| T1059.007 | JavaScript | JS执行 | 中 |
| T1053 | 调度任务/作业 | 通过计划任务执行 | 高 |
| T1053.005 | Windows任务调度 | at/schtasks创建计划任务 | 高 |
| T1053.003 | Cron | Linux cron定时任务 | 高 |
| T1106 | 原生API | 直接调用系统API | 中 |
| T1047 | WMI | Windows管理 instrumentation | 高 |

**检测重点**：

1. **PowerShell（T1059.001）**
   - 监控：`powershell.exe -enc`、`-encodedcommand`
   - 关注无窗口PowerShell（`-WindowStyle Hidden`）
   - 启用PowerShell日志（模块日志、脚本块日志）
   - AMSI（反恶意软件扫描接口）挂钩

2. **计划任务（T1053）**
   - 监控新建的计划任务（特别是高权限账户创建）
   - 检查非标准路径下的计划任务（如temp目录）
   - Windows: `schtasks /query /fo CSV`
   - Linux: `crontab -l`、`/etc/cron.d/`

**防御建议**：
- 限制PowerShell使用（AppLocker/WinFW）
- 禁用不必要的脚本解释器
- 监控计划任务创建事件（Windows Event 4698）
- 最小化高权限账户创建计划任务的权限

### 2.5 TA0003 持久化（Persistence）

**目标**：在系统重启、凭证更换等情况下保持访问权限。

这是区分普通攻击和高级威胁的关键阶段。

| 技术ID | 技术名称 | 描述 | 检测难度 |
|--------|----------|------|----------|
| T1547 | 引导或登录自启动执行 | 注册表Run键、启动文件夹 | 中 |
| T1547.001 | 注册表Run键/启动文件夹 | HKCU/HKLM Run键 | 低 |
| T1543 | 创建/修改系统进程 | 创建新服务或修改现有服务 | 高 |
| T1543.003 | Windows服务 | 创建恶意Windows服务 | 中 |
| T1050 | 新服务 | 安装为新服务 | 中 |
| T1050.003 | Windows服务 | sc create创建服务 | 中 |
| T1037 | 引导或登录初始化脚本 | 登录脚本、启动脚本 | 中 |
| T1078 | 有效账户 | 使用合法账户作为持久化手段 | 低 |
| T1098 | 账户操作 | 修改账户属性维持访问 | 高 |
| T1098.001 | 添加Office 365全局管理员 | 云账户持久化 | 中 |
| T1546 | 事件触发执行 | 通过特定事件触发恶意代码 | 高 |
| T1546.003 | WMI事件订阅 | 创建WMI永久性事件消费者 | 高 |
| T1546.008 | 辅助功能 | 替换粘滞键、放大镜等 | 低 |

**高价值持久化检测点**：

1. **注册表持久化**
   ```
   重点监控注册表键：
   - HKLM\Software\Microsoft\Windows\CurrentVersion\Run
   - HKCU\Software\Microsoft\Windows\CurrentVersion\Run
   - HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnce
   - HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon
   ```

2. **计划任务**
   ```powershell
   # 查找可疑计划任务
   Get-ScheduledTask | Where-Object {
       $_.Actions.Execute -match "temp|appdata|downloads"
   }
   ```

3. **服务创建**
   ```cmd
   sc query | findstr SERVICE_NAME
   ```

**防御建议**：
- 限制用户创建计划任务/服务的权限
- 启用注册表监控（Sysmon Event 12/13/14）
- 定期审计账户和权限变更
- 使用EDR监控新增/修改的系统组件

### 2.6 TA0004 权限提升（Privilege Escalation）

**目标**：从普通用户权限提升到管理员或系统权限。

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1068 | 利用漏洞提权 | 利用软件漏洞获取高权限 | 高 |
| T1068.001 | 利用漏洞（通用） | 通用漏洞利用 | 高 |
| T1068.008 | Windows漏洞 | Windows内核/本地提权漏洞 | 高 |
| T1548 | 滥用访问控制机制 | 绕过UAC、利用sudo | 高 |
| T1548.002 | 绕过UAC | 利用白名单程序、自适应提升 | 高 |
| T1548.003 | Sudo和Sudo缓存滥用 | 无需密码sudo、sudo缓存 | 高 |
| T1078 | 有效账户 | 使用已有的高权限账户 | 极高 |
| T1055 | 进程注入 | 将代码注入其他进程 | 高 |
| T1055.001 | DLL注入 | 动态链接库注入 | 高 |
| T1055.012 | 进程 hollowing | 替换进程内存 | 中 |
| T1574 | 劫持执行流 | DLL劫持、执行流重定向 | 高 |
| T1574.001 | DLL搜索顺序劫持 | 将恶意DLL放在搜索路径前 | 高 |

**Windows提权检测重点**：

1. **UAC绕过**
   - Event 4672（特殊权限分配）
   - Event 4688（新进程创建，TokenType=TokenElevationTypeFull）
   - 检查可信程序列表是否被修改

2. **令牌操纵**
   - 查看是否有进程以高权限运行但父进程是低权限
   - 检查Token截取（Incognito、Mimikatz）

3. **提权漏洞利用**
   - 监控已知提权漏洞的利用工具（如Juicy Potato、Print Spoofer）
   - Windows: `whoami /priv` 查看当前权限
   - 关注SeImpersonate等高价值权限

**Linux提权检测重点**：

1. **Sudo滥用**
   - 检查`/etc/sudoers`和用户sudo权限
   - 查找可sudo执行的危险命令（vim, less, more, nmap等）
   - 监控`/var/log/auth.log`中的sudo使用

2. **SUID文件**
   ```bash
   find / -perm -4000 -type f 2>/dev/null
   ```

3. **内核漏洞**
   - 关注内核版本和已知内核漏洞
   - 使用`uname -r`检查内核版本

| T1070 | 清除主机指标 | 删除日志、清除痕迹 | 极高 |
| T1070.001 | 清除Windows事件日志 | wevtutil、PowerShell清除日志 | 高 |
| T1070.004 | 文件删除 | 工具删除文件 | 极高 |
| T1562 | 损害防御 | 禁用或修改安全工具 | 高 |
| T1562.001 | 禁用安全工具 | 禁用AV/EDR/防火墙 | 高 |
| T1562.004 | 禁用系统防火墙 | netsh/wfwutil关闭防火墙 | 高 |
| T1218 | 系统二进制代理执行 | 利用可信程序执行恶意操作 | 高 |
| T1218.005 | Mshta | mshta.exe执行HTA/JS | 高 |
| T1218.004 | InstallUtil | 利用InstallUtil绕过限制 | 中 |
| T1218.011 | Verclsid | 利用Verclsid执行 | 中 |
| T1036 | 伪装 | 伪装成合法程序 | 高 |
| T1036.005 | 匹配合法名称或位置 | 放在System32等目录 | 高 |
| T1036.007 | 双扩展名 | report.pdf.exe | 低 |
| T1078 | 有效账户 | 使用合法凭证避免检测 | 极高 |

**防御规避检测重点**：

1. **进程链分析**
   - 异常父进程关系（如Word/Excel启动PowerShell）
   - Sysmon Event 1：`ParentImage` + `Image` 组合分析
   - 重点关注：无窗口PowerShell被Office/浏览器启动

2. **命令行审计**
   - 记录所有命令行参数（EDR/Sysmon）
   - 检测Base64解码模式：`powershell -enc`、`-encodedcommand`
   - 检测可疑路径：`temp`、`appdata`、`downloads`中的可执行文件

3. **文件操作监控**
   - Sysmon Event 11：文件创建
   - 关注`.tmp`、`.vbs`、`.js`、`.exe`在temp目录
   - 监控System32/Windows目录下非授权文件创建

4. **日志完整性**
   - 监控Event Log清除事件（Windows Event 1102）
   - 监控安全日志被清空

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1003 | OS凭证转储 | 从系统提取凭证 | 极高 |

| T1110.001 | 密码猜测 | 使用常见密码尝试 | 高 |
| T1110.003 | 密码喷洒 | 一个密码试多个账户 | 高 |
| T1110.004 | 凭证撞库 | 使用泄露凭证 | 高 |
| T1558 | 窃取或伪造Kerberos票据 | Kerberos攻击 | 高 |
| T1558.001 | 黄金票据 | 伪造KRBTGT TGT | 高 |
| T1558.002 | 白银票据 | 伪造服务票据 | 高 |

| T1552.004 | 云实例元数据API | 从云IMDS获取凭证 | 高 |

**凭证访问检测重点**：

1. **凭证转储检测**
   - LSASS访问：启用Credential Guard
   - 监控Lsass.exe的子进程（非svchost.exe）
   - 监控Mimikatz特征：`mimidrv.sys`加载、`sekurlsa::logonpasswords`
   - 检测工具指纹：特定文件名、进程名、内存特征

2. **暴力破解检测**
   ```
   Windows登录失败阈值：
   - 单账户：5-10次失败/15分钟 → 告警
   - 账户锁定：5-10次失败 → 账户锁定

   密码喷洒特征：
   - 多个账户在短时间内各有1-2次失败
   - 失败时间集中在同一时间段
   ```

3. **Kerberos攻击检测**
   ```
   Kerberoasting特征：
   - TGS-REQ请求（4768）大量SPN账户
   - 加密类型为RC4（而非AES）
   - 短时间内大量TGS请求

   黄金票据特征：
   - TGT（4768）的`icket encryption type`为RC4
   - TGT的starttime和endtime间隔异常大
   - 来源IP异常（非常见来源）

   暴力破解特征：
   - 4768事件大量错误请求
   - 目标账户为高价值账户（admin、service）
   ```

4. **云凭证检测**
   - 监控云IMDS（169.254.169.254）访问
   - 检查异常IAM API调用模式
   - 监控凭证创建和权限变更

**防御建议**：
- 启用Credential Guard（Windows）
- 启用Protected Process Light for LSASS
- 禁用WDigest认证
- 强制Kerberos AES加密（禁用RC4）
- 实施账户锁定策略
- 定期审计服务账户SPN
- 实施LAPS（本地管理员密码解决方案）

**发现阶段检测**：

发现阶段通常是攻击的早期阶段，检测到发现行为可以提前预警。

1. **账户枚举**
   ```
   Windows: net user /domain、net group "Domain Admins" /domain
   告警阈值：非IT管理员账户执行域枚举
   ```

2. **网络扫描**
   - 监控内网端口扫描（分段禁止）
   - 监控对多个主机的快速连接
   - DNS查询异常（指向内部主机）

3. **安全工具发现**
   ```
   常见检测命令：
   - tasklist /v | findstr "av\|edr\|defender\|carbon\|crowd"
   - wmic /namespace:\\root\securitycenter2 path *state
   - systemctl list-units --type=service | grep -i "av\|defend"
   - ls /proc/$(id)/fd | xargs ls -l | grep -i av
   ```

### 2.10 TA0008 横向移动（Lateral Movement）

**目标**：在网络中的系统之间移动，扩大控制范围。

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1021 | 远程服务 | 利用远程服务 | 极高 |
| T1021.001 | 远程桌面协议 | RDP横向 | 高 |
| T1021.002 | SMB/Windows管理共享 | PsExec、WMI、SMBExec | 极高 |
| T1021.004 | SSH | SSH横向 | 高 |
| T1021.005 | Windows远程管理 | WinRM横向 | 高 |
| T1574 | 凭证传递攻击 | Pass-the-Hash/Pass-the-Ticket | 极高 |
| T1574.002 | Pass-the-Hash | NTLM hash重用 | 极高 |
| T1574.004 | Pass-the-Ticket | Kerberos票据重用 | 高 |
| T1210 | 利用远程服务 | 利用服务漏洞横向 | 高 |
| T1072 | 软件部署工具 | SCCM、PDQ Deploy横向 | 中 |
| T1072.001 | 管理工具 | 利用管理工具执行命令 | 高 |
| T1072.002 | GPO更新 | 通过GPO横向 | 中 |
| T1534 | 内部钓鱼 | 从已入侵账户发起钓鱼 | 中 |

**横向移动检测重点**：

1. **RDP横向**
   ```
   检测特征：
   - 非工作时间RDP登录
   - 登录源IP为工作站（非跳板机）
   - 登录到高价值服务器
   - 短时间内大量RDP连接
   - 告警阈值：单用户访问>5台主机/小时
   ```

2. **SMB/WMI横向**
   ```
   检测特征：
   - 横向工具执行（psexec.py、wmiexec.py、crackmapexec）
   - SMB lateral tool特征端口（445连接+ SMBexec/LSARPC）
   - 非管理员账户执行高权限操作
   ```

3. **凭证传递**
   ```
   Pass-the-Hash检测：
   - 登录事件中TargetUser和TargetOriginName不匹配
   - 使用哈希而非密码的登录
   - Event 4624的LogonType和IpAddress组合异常

   Pass-the-Ticket检测：
   - 4768 TGS-REQ使用RC4加密（非AES）
   - 来源IP不是常见KDC来源
   - TGT的有效期异常
   ```

4. **SSH横向**
   ```
   检测特征：
   - 密钥登录而非密码登录
   - 非跳板机发起的SSH连接
   - 短时间内多个SSH会话
   - 异常时间段的SSH活动
   ```

**防御建议**：
- 实施RDP跳转服务器（Jump Server）
- 禁用网络级别认证（NLA）强制（部分缓解）
- 监控本地管理员账户使用
- 实施Protected Users安全组
- 禁用NTLM认证
- 网络分段，限制横向移动路径

   ```

3. **数据暂存检测**

   - temp/appdata目录的异常大文件

   - 特定时间窗口的写入操作
   ```

### 2.12 TA0011 命令与控制（Command and Control）

**目标**：建立攻击者的远程控制通道。

这是最关键的检测点之一——阻断C2就等于终止攻击。

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1071 | 应用层协议 | C2通过HTTP/S、DNS | 极高 |
| T1071.001 | Web协议 | HTTP/S C2 | 极高 |
| T1071.004 | DNS | DNS C2 | 高 |
| T1105 | 入口工具转移 | 下载额外工具 | 极高 |
| T1104 | 多阶段通道 | 多个C2通道 | 中 |
| T1095 | 非应用层协议 | ICMP、TCP raw C2 | 中 |
| T1095.001 | ICMP隧道 | ICMP隧道 | 中 |
| T1572 | 协议隧道 | 隧道化C2 | 中 |
| T1572.001 | SSH隧道 | SSH隧道C2 | 高 |
| T1573 | 加密通道 | 加密的C2通信 | 高 |
| T1573.001 | 对称加密 | 自定义对称加密C2 | 高 |
| T1573.002 | 非对称加密 | RSA加密C2 | 高 |
| T1102 | Web服务 | 利用合法Web服务C2 | 中 |
| T1102.002 | 双向通信 | 使用GitHub、Twitter等C2 | 中 |
| T1205 | 流量信号 | 端口敲门 | 中 |

**C2检测重点**：

1. **HTTP/S C2**
   ```
   检测特征：
   - 异常长连接（长期保持的HTTP连接）
   - 固定间隔请求（信标特征）
   - 非浏览器UA
   - 异常端口的HTTPS流量
   - 异常域名（随机字符串、DGA）
   - 大小固定的请求/响应
   ```

2. **DNS C2**
   ```
   检测特征：
   - 大量异常子域名查询
   - 查询域名与权威DNS不匹配
   - TXT/HTTPS记录异常大响应
   - DNS隧道（数据量、查询频率异常）
   - 长随机子域名（可能为DGA）
   ```

3. **ICMP隧道**
   ```
   检测特征：
   - 异常大小的ICMP包（>64字节）
   - ICMP流量占比异常
   - 非正常来源的ICMP包
   ```

4. **Beaconing检测**
   ```
   统计检测：
   - 信标间隔（Jitter分析）
   - 流量大小模式
   - 时间间隔直方图
   - 与已知C2框架特征匹配
   ```

**防御建议**：
- DNS安全（DNS over HTTPS监控、DNS日志分析）
- 网络分段（限制C2通信路径）
- 应用代理（深度检测HTTP/HTTPS流量）
- 威胁情报（已知恶意域名/IP黑名单）
- EDR行为检测（异常进程网络行为）

### 2.13 TA0010 数据泄露（Exfiltration）

**目标**：将收集到的数据传输到攻击者控制的位置。

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1041 | 通过C2通道泄露 | 利用现有C2通道传输数据 | 高 |
| T1567 | 通过Web服务泄露 | 利用云服务/邮件泄露 | 高 |
| T1567.002 | 代码仓库泄露 | Push到GitHub私有仓库 | 中 |
| T1567.001 | 云存储泄露 | 上传到云存储 | 中 |
| T1048 | 通过替代协议泄露 | FTP、SFTP、SMTP | 中 |
| T1052 | 通过物理介质泄露 | USB、光盘 | 中 |
| T1030 | 数据传输大小限制 | 分块传输 | 中 |

**数据泄露检测重点**：

1. **网络流量分析**
   ```
   检测特征：
   - 单方向大数据量外传
   - 非工作时间的大量上传
   - 上传到非常见目的地
   - 加密流量中异常大的上传
   - 协议异常（如HTTPS大响应）
   ```

2. **DLP告警**
   ```
   触发场景：
   - 敏感文件外发（非授权渠道）
   - 大量文件外发
   - 包含敏感关键词的邮件外发
   - 云存储上传（未授权）
   ```

3. **云存储泄露**
   ```
   检测特征：
   - 异常API调用创建云存储资源
   - S3 bucket创建 + 大量PUT请求
   - 异常位置的上传（境外）
   - 异常时间段的上传
   ```

**防御建议**：
- 部署DLP系统
- 实施云访问安全代理（CASB）
- 网络出口监控
- 敏感数据分类和标记
- 数据泄露隔离技术

### 2.14 TA0040 影响（Impact）

**目标**：对数据或系统造成破坏、加密或勒索。

| 技术ID | 技术名称 | 描述 | 流行度 |
|--------|----------|------|--------|
| T1486 | 数据加密影响 | 勒索软件加密 | 极高 |
| T1490 | 禁止系统恢复 | 删除备份、VSS | 高 |
| T1490.001 | 删除卷影副本 | vssadmin delete shadows | 高 |
| T1489 | 服务停止 | 停止关键服务 | 中 |
| T1485 | 数据销毁 | 彻底破坏数据 | 中 |
| T1491 | 网站篡改 | 修改网站内容 | 低 |
| T1491.001 | 内部篡改 | 内部系统页面修改 | 中 |
| T1484 | 域信任修改 | 修改AD信任关系 | 中 |

**影响阶段检测**：

1. **勒索软件**
   ```
   早期特征：
   - 文件创建和修改突然增多（加密前兆）
   - 特定文件类型被修改（.encrypted、.locked等）
   - 卷影副本被删除
   - 大量.tmp文件创建

   确认特征：
   - 文件扩展名被修改
   - 勒索信出现（README.txt等）
   - 桌面背景被修改
   ```

2. **备份破坏**
   ```
   检测特征：
   - vssadmin delete shadows执行
   - 备份软件被停止
   - 备份文件被删除
   - 备份脚本被修改
   ```

### 3.1 完整攻击链示例

```

2. 资源开发 → T1587: 购买定制化木马

6. 权限提升 → T1068: 利用Win32k本地提权漏洞
7. 防御规避 → T1027: 木马代码混淆
8. 凭证访问 → T1003.001: 内存中提取浏览器保存的密码
9. 发现 → T1087.002: 枚举域用户
10. 横向移动 → T1574.002: Pass-the-Hash横向到域控
11. 收集 → T1005: 收集敏感文档
12. 命令控制 → T1071.001: HTTP C2通信
13. 泄露 → T1567.001: 上传到攻击者云存储
14. 影响 → T1486: 部署勒索软件加密（攻击最后阶段）
```
