# AD 基础与安全调查

## 1. 目标

建立 Active Directory 调查的最小基础框架，支持账号异常、横向移动、权限提升和域内持久化分析。

## 2. 需要掌握的对象

- 用户
- 组
- 计算机账户
- 域控
- OU
- GPO
- 服务主体名称（SPN）

## 3. 高价值调查方向

- 异常登录与票据行为
- 管理员组变更
- 新建账号 / 异常启用账号
- 域控访问异常
- Kerberoasting / AS-REP Roasting
- 委派、信任、服务账号滥用

## 4. 常见日志与数据源

- Windows 安全日志
- 域控事件日志
- EDR
- 身份平台审计

## 5. 典型调查步骤

1. 明确异常账号和时间窗
2. 检查 `4624/4625/4672/4768/4769/4771`
3. 检查组变更和密码重置
4. 检查是否有同源 IP、同设备、同票据异常
5. 结合主机侧日志看是否已横向移动

## 6. 常见风险点

- 高权限账号未分级
- 服务账号权限过大
- 长期有效票据
- MFA 缺失
- 弱口令或密码复用
