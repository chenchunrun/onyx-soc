# 邮件网关钓鱼分析指南

## 1. 目标

用于指导分析邮件网关、邮箱审计和用户反馈中出现的钓鱼事件。

## 2. 调查输入

- 邮件主题
- 发件人地址
- 收件人范围
- 邮件头部
- 附件样本
- URL 列表
- 邮件网关 verdict

## 3. 核心分析维度

### 发件可信度

- SPF / DKIM / DMARC
- 发件域名是否仿冒
- Reply-To 与显示名是否不一致

### 内容特征

- 紧急付款、验证码、密码过期、共享文档
- 登录页面仿冒
- 附件类型异常

### IOC 提取

- URL
- 域名
- IP
- 附件 hash
- 发件地址

## 4. 排查范围

- 同主题是否批量投递
- 是否有人点击
- 是否有人下载或打开附件
- 是否已触发 EDR、代理、身份异常登录

## 5. 常见结论类型

- 纯垃圾邮件
- 钓鱼诱导登录
- 附件投递恶意载荷
- 内部账号发信被滥用

## 6. 处置动作

- 搜索并删除同主题邮件
- 封禁 IOC
- 通知收件人
- 对点击/输入凭证的用户启动账号或终端调查
