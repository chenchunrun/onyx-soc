# AD 登录与 Kerberos 调查

## 1. 目标

用于排查 Active Directory 场景下的异常登录、票据滥用、横向移动与账号接管问题。

## 2. 核心调查对象

- 用户账号
- 计算机账号
- 域控
- 服务账号
- SPN
- Kerberos TGT / TGS 请求

## 3. 关键事件

| 事件 ID | 含义 | 调查意义 |
| --- | --- | --- |
| 4624 | 登录成功 | 看登录类型、来源、目标主机 |
| 4625 | 登录失败 | 看爆破、错误密码、异常来源 |
| 4648 | 显式凭证登录 | 常见于横向移动 |
| 4672 | 特权登录 | 高权限行为 |
| 4768 | TGT 请求 | 首次 Kerberos 认证 |
| 4769 | 服务票据请求 | Kerberoasting、横向访问 |
| 4771 | 预认证失败 | AS-REP、爆破、时钟偏差 |

## 4. 常见攻击场景

### Kerberoasting

关注点：
- 某账号短时间请求多个服务票据
- 目标为高价值 SPN
- 请求后伴随离线破解或横向访问

### Password Spraying

关注点：
- 多账号、少次数失败
- 同源 IP、短时间窗
- 失败后紧接成功登录

### Pass-the-Ticket / 横向移动

关注点：
- 异常主机间访问
- 显式凭证登录
- 高权限账号出现在非日常管理主机

## 5. 推荐调查步骤

1. 确定异常账号和时间窗
2. 查 `4624/4625/4648/4672`
3. 查 `4768/4769/4771`
4. 识别来源主机、目标主机、票据模式
5. 与 EDR / 终端进程树交叉验证
6. 判断是否需要隔离主机、重置账号、撤销票据
