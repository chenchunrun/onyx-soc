# 防火墙日志调查要点

## 1. 目标

用于对网络边界、南北向流量和横向流量中的可疑连接进行快速排查。

## 2. 关键字段

- 源 IP
- 目标 IP
- 源端口
- 目标端口
- 协议
- 动作（allow / deny / reset）
- 设备 / zone / policy
- NAT 前后地址
- 会话持续时间
- 字节数 / 包数

## 3. 优先调查场景

- 内网主机对外连接异常国家或高风险 ASN
- 短时间高频拒绝连接
- 到非常规端口的长连接
- 域控、堡垒机、数据库、核心系统的异常出站
- 横向访问与策略命中异常

## 4. 调查步骤

1. 明确可疑 IP、端口、时间窗
2. 确认策略命中和动作
3. 确认是否有 NAT
4. 与 EDR / 主机日志交叉验证
5. 判断是扫描、回连、外联还是业务误报

## 5. 常见判断线索

- 高频短连接：扫描、探测、失败爆破
- 稳定长连接：回连、代理、隧道
- 特定端口出站：数据传输、C2、远控
- deny 激增：策略变更、失效配置、异常探测
