# Windows 安全事件 ID 速查

## 1. 目标

用于安全分析、账号调查、主机入侵排查时快速定位关键 Windows 事件。

## 2. 常见登录与认证事件

| 事件 ID | 含义 | 关注点 |
| --- | --- | --- |
| 4624 | 登录成功 | 登录类型、来源 IP、账号、主机 |
| 4625 | 登录失败 | 暴力破解、来源、失败原因 |
| 4634 | 会话退出 | 会话时长、是否异常中断 |
| 4648 | 显式凭证登录 | 是否存在横向移动或凭证滥用 |
| 4672 | 特权登录 | 高权限账号是否异常 |
| 4768 | Kerberos TGT 请求 | 是否存在异常用户/来源 |
| 4769 | Kerberos 服务票据 | 是否存在 Kerberoasting 痕迹 |
| 4771 | Kerberos 预认证失败 | 爆破、错误密码、时钟问题 |

## 3. 账号与权限相关事件

| 事件 ID | 含义 | 关注点 |
| --- | --- | --- |
| 4720 | 创建用户 | 是否为未授权创建 |
| 4722 | 启用用户 | 谁启用、何时启用 |
| 4723 | 尝试修改密码 | 是否异常账号操作 |
| 4724 | 重置密码 | 是否为恶意接管 |
| 4728 | 添加到高权限组 | 管理员组变更 |
| 4732 | 添加到本地组 | 本地提权 |

## 4. 调查建议

- 登录调查优先看 `4624/4625/4648/4672`
- AD 调查补看 `4768/4769/4771`
- 权限调查补看 `4720/4724/4728/4732`
