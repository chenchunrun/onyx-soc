# 工单流转与升级路径

## 目标

- 明确告警从发现到关闭的流转路径
- 明确什么时候升级到更高层级或跨团队处理

## 标准流转

1. 告警接收
2. 初筛分级
3. 证据补充
4. 是否立案
5. 遏制与处置
6. 恢复验证
7. 复盘与关闭

## 与当前安全自动化能力的对应关系

- `search_security_alerts`：用于告警检索和首轮证据补充
- `lookup_asset_context`：用于补充资产归属和业务影响
- `create_security_ticket`：用于立案或补充工单
- `send_security_alert`：用于升级通知
- `isolate_endpoint_host`：用于终端遏制

## 工单最小字段

- 工单编号
- 告警来源
- 分级
- 责任人
- 影响资产
- 影响账号
- 当前状态
- 截止时间
- 下一步动作

## 建议分工

- 值班分析师：首轮研判、补证、定级建议
- 响应负责人：最终定级、升级决策、跨团队协调
- 平台团队：执行平台侧隔离、封禁、日志补采
- 业务团队：确认业务影响与恢复窗口

## 典型状态

- New
- Investigating
- Contained
- Pending External Team
- Resolved
- Closed

## 简化状态机

`New -> Investigating -> Contained -> Resolved -> Closed`

补充分支：

- `Investigating -> Pending External Team`
- `Pending External Team -> Investigating`
- `Resolved -> Investigating`：恢复后再次发现风险时回退

## 立案标准

- 达到 `P1/P2`
- 涉及关键资产或高权限账号
- 需要跨团队协同
- 需要执行正式遏制动作
- 需要形成复盘记录

## 升级路径建议

### 值班分析师 -> 响应负责人

- 达到 P1 / P2
- 涉及关键资产
- 需要隔离、封禁、停机等高影响动作

### 响应负责人 -> 平台/业务团队

- 需要主机、网络、邮件、身份、云团队协同
- 需要回滚生产变更
- 需要业务确认影响范围

### 响应负责人 -> 管理层/合规/法务

- 涉及数据泄露
- 涉及监管通报
- 涉及对外披露

## 超时处理

- 超过 SLA 未响应时自动提醒
- 超过 SLA 未处置时自动升级
- 关键事件未更新时需要值班交接说明

## 关闭前检查

- 关键风险已遏制
- 影响范围已确认
- 工单证据已补齐
- 恢复动作已验证
- 是否需要进入复盘已明确
