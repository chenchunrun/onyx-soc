# EDR平台操作手册

## 平台信息

- 平台名称：终端检测与响应平台
- 接入方式：通过 `lookup_asset_context`、`isolate_endpoint_host` 工具或平台原生控制台
- 当前用途：查询主机上下文、确认终端告警、执行隔离
- 对应自动化能力：`lookup_asset_context`、`isolate_endpoint_host`

## 常用操作

- 查询主机
- 查询进程树
- 查询文件哈希
- 查询网络连接
- 查询登录用户与会话
- 隔离主机
- 解除隔离

## 调查最小动作

1. 用 `lookup_asset_context` 或主机名查清资产归属、业务属性、关键程度。
2. 拉取进程树，确认可疑进程及父子链路。
3. 拉取关键文件路径、哈希、签名状态。
4. 拉取近时间窗网络连接，确认是否有恶意 C2 或异常横向移动。
5. 核对当前登录用户、最近登录历史、是否存在高权账号。

## 典型进程树样例

### Office 派生脚本

- `WINWORD.EXE -> powershell.exe -> curl.exe`
- 风险点：文档诱导、脚本下载、后续落地执行

### 邮件客户端派生命令

- `OUTLOOK.EXE -> cmd.exe -> mshta.exe`
- 风险点：钓鱼邮件、恶意链接、远程脚本执行

### 合法进程伪装

- `explorer.exe -> rundll32.exe -> <异常 DLL>`
- 风险点：白利用、持久化、规避检测

## 高风险动作审批建议

- 主机隔离
- 批量封禁
- 远程删除文件
- 杀死关键业务进程
- 在关键生产主机上执行强制终止

## 隔离建议

### 可以直接隔离

- 非生产终端已确认恶意执行
- 存在明显横向移动或持续外联
- 账号失陷后终端被用于恶意操作

### 需要先沟通再隔离

- 核心业务主机
- 关键跳板机
- 域控、数据库、中间件等基础设施
- 可能影响大规模用户访问的系统

## 常见问题

- Agent 不在线：先确认主机是否离线、被卸载、网络被阻断
- 终端数据延迟：核对平台代理状态和采集策略
- 主机重复命名：使用资产 ID、IP、业务标签交叉确认
- 哈希缺失：补查磁盘路径、文件元数据或用备选工具采集
- 资产上下文不足：去资产平台补查所有者、系统用途、重要性

## 输出建议

- 主机名
- 用户
- 关键进程
- 关键文件
- 关键连接
- 资产重要性
- 是否建议隔离
- 隔离前风险说明

## 调查结论模板

- 结论：误报 / 可疑 / 已确认恶意
- 关键证据：进程树、文件、网络、登录信息
- 影响范围：单机 / 多机 / 是否涉及关键资产
- 处置建议：继续观察 / 立案 / 隔离 / 升级
