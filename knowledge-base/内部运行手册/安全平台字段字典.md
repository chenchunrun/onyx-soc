# 安全平台字段字典

## 用途

- 统一 SIEM / EDR / 工单 / 资产平台字段口径
- 便于告警解析、自动化编排、规则设计

## 建议字段

### 主体信息

- `user`
- `user_id`
- `email`
- `role`

### 资产信息

- `hostname`
- `asset_id`
- `ip`
- `mac`
- `business_unit`
- `criticality`

### 告警信息

- `alert_id`
- `alert_name`
- `severity`
- `category`
- `source_platform`

### 调查信息

- `event_time`
- `ingest_time`
- `process_name`
- `command_line`
- `file_hash`
- `url`
- `domain`

### 工单信息

- `ticket_id`
- `assignee`
- `status`
- `sla_due_at`

## 字段实表示例

| 字段名 | 含义 | 常见来源 | 示例值 | 备注 |
| --- | --- | --- | --- | --- |
| `alert_id` | 告警唯一编号 | SIEM / EDR | `ALERT-20260408-001` | 用于串联工单与调查记录 |
| `hostname` | 主机名 | EDR / 资产平台 | `WIN-SEC-001` | 优先配合 `asset_id` 使用 |
| `asset_id` | 资产唯一标识 | CMDB / 资产平台 | `AST-004218` | 比主机名更稳定 |
| `user` | 账号标识 | 身份平台 / SIEM | `zhangsan` | 注意与邮箱字段区分 |
| `email` | 邮箱地址 | 身份平台 / 邮件平台 | `zhangsan@example.com` | 用于邮件调查和账号关联 |
| `src_ip` | 源 IP | 网络 / SIEM / EDR | `10.10.4.12` | 注意 NAT 场景 |
| `dst_ip` | 目标 IP | 网络 / SIEM / EDR | `8.8.8.8` | 常用于外联调查 |
| `process_name` | 进程名 | EDR | `powershell.exe` | 常与 `command_line` 组合使用 |
| `command_line` | 命令行 | EDR | `powershell -enc ...` | 对脚本类调查非常关键 |
| `file_hash` | 文件哈希 | EDR / 沙箱 | `sha256:...` | 尽量明确算法类型 |
| `severity` | 风险等级 | SIEM / 工单 | `high` | 建议映射到 P1-P4 |
| `ticket_id` | 工单编号 | 工单平台 | `SEC-1428` | 应与 `alert_id` 双向可追踪 |

## 字段使用原则

- 一个对象尽量同时保留“显示字段”和“稳定 ID”
- 用户、资产、告警、工单至少各有一个唯一标识
- 时间字段必须明确时区或统一使用 UTC
- 不同平台字段要维护映射关系，不要依赖人工记忆

## 推荐映射关系

- `severity -> P1/P2/P3/P4`
- `hostname -> asset_id -> business_unit`
- `user -> email -> role`
- `alert_id -> ticket_id`

## 优先补齐的字段

- 用户唯一标识
- 资产唯一标识
- 时间字段口径
- 告警等级映射
- 工单状态映射

## 维护建议

- 每个字段写清楚来源平台
- 每个字段写清楚是否必填
- 写清格式、示例值、枚举值
- 写清字段之间的映射关系
- 每次平台字段变更都需要同步更新这份字典
