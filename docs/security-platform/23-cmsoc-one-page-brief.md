# CMSOC 网络安全智能平台（一页版）

## 1. 产品一句话

CMSOC 是面向企业安全运营团队的智能工作台，将安全智能体、专业 Skill、内部知识和安全工具链融合到统一对话入口，帮助团队更快完成“发现风险、判断影响、制定处置”的闭环。


## 2. 适用客户与场景

- 安全运营中心（SOC）：告警研判、事件分流、升级决策。
- 漏洞管理团队：CVE 影响评估、修复优先级排序、缓解建议。
- 应急响应团队：事件初判、影响面梳理、处置协同与复盘输出。
- 安全管理者：统一查看风险态势、处置进展和能力覆盖。


## 3. 核心能力

- 安全智能体：内置漏洞评估专家、恶意软件分析师、事件分析师等角色化能力。
- 安全 Skill：资产发现、漏洞研究、SCA 分析、告警分析等任务化能力按需启用。
- 企业知识检索：联动内部文档、情报、历史报告，输出可追溯的分析依据。
- 工具编排集成：可接入 CMDB、SIEM、EDR、工单系统和情报平台，形成自动化联动。
- 运行时治理：高风险能力默认受控，支持授权启用、审计留痕和策略边界。


## 4. 客户价值

- 更快：将跨系统检索与汇总压缩为一次对话任务。
- 更准：基于证据链生成结论，降低噪声和主观偏差。
- 更稳：智能体 + Skill + 工具联动，形成可复制的安全分析流程。
- 更易落地：支持从 PoC 到生产的平滑演进，兼容企业现有安全栈。


## 5. 典型工作流（以漏洞评估为例）

1. 输入 CVE 编号或漏洞描述。
2. 智能体自动路由到“漏洞评估专家”，并推荐对应 Skill。
3. 系统检索内部情报和资产上下文，必要时调用外部工具。
4. 输出影响范围、优先级、缓解建议和处置清单。
5. 结果可直接用于安全周报、管理汇报或工单流转。


## 6. 部署与集成方式

- 本地演示：适合方案验证与联合 PoC。
- 私有化部署：接入企业身份、权限、日志和安全网关。
- 分层集成：按阶段接入知识库、告警平台、资产平台和响应工具。


## 7. 商务与合规说明

- 社区版能力遵循 MIT 开源许可，可用于二次开发与商业化交付。
- 企业增强能力与支持服务可按项目制或订阅制提供。
- 发布前可通过内置合规清单快速确认交付边界与许可证范围。


## 8. 对外沟通建议话术

“CMSOC 不是替代安全团队，而是把重复的信息检索、情报归并和分析编排自动化，让安全专家把时间投入到更高价值的判断和决策上。”
